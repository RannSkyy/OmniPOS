# 🚀 Core Features & Functionality

This application includes fully functional and dynamic features powered by real application logic rather than static mock data.

## 🛒 Interactive POS Workspace (Terminal Demo)

A fully interactive Point of Sale (POS) simulator that allows users to:

* Browse and search Nike footwear and sportswear products.
* Filter products by category.
* View detailed product specifications.
* Switch between available size and color variations.
* Add products directly to the cashier shopping cart.
* Experience a realistic retail checkout workflow through a responsive POS interface.

## 💳 Dynamic Checkout & Receipt System

The cashier simulation supports complete transaction processing, including:

* Automatic subtotal calculation.
* Flexible promotional discount codes:

  * `NEWUSER` — 10% discount
  * `FITSALE` — 15% discount
* Automatic service tax calculation (12%).
* Multiple payment method selection.
* Real-time product stock reduction after successful transactions.
* Dynamically generated printable transaction receipts.

## 📩 Contact Form & Local Message Storage

A complete contact system featuring client-side validation and secure local data persistence:

* Name validation.
* Email format validation.
* Retail partnership subject selection.
* Message content validation (minimum 10 characters).
* Secure message storage using browser Local Storage.
* Message history table for reviewing previously submitted inquiries.

## 🧭 Smooth Navigation & Floating Controls

Enhanced user experience features designed for seamless browsing:

* Smooth-scrolling anchor navigation links.
* Automatic active-section detection based on scroll position.
* Responsive top navigation bar behavior.
* Floating "Back to Top" button that appears when users scroll beyond a predefined viewport threshold.
* Optimized navigation performance across desktop and mobile devices.
